## 🔧 技术栈

### 后端框架

- **Python**: 3.9+
- **AsyncIO**: 异步编程
- **Anthropic SDK**: API 调用

### 核心依赖

```

python-dotenv>=1.0.0       # 环境变量管理
```

### API

- **模型**: 智谱 GLM-4.7（Claude API 兼容）
- **协议**: HTTP + SSE
- **特性**: 流式响应、工具调用

## 🚀 立即使用

### 快速启动

```bash
# 1. 进入项目目录
cd agents/v1

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境（已有 .env 文件）

# 4. 启动 Agent
python3 main.py
```

### 开始对话

```
You: 启动一个 sleep 进程，名称 test，时间 10 秒

Agent: 我来帮你启动进程。

[调用工具: start_process] ✓

进程已启动！PID: 12345
```

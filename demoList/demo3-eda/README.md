# 数字芯片设计流程学习项目

## 项目目标

通过实践和文档学习数字芯片设计的完整流程，理解每个阶段的目标、输入输出、关键交付物和核心指标。

## 数字芯片设计流程概览

```
规格定义 → RTL设计 → 功能验证 → 综合 → 网表验证 → 布局布线 → 时序分析 → 物理验证 → 流片
```

## 项目结构

```
demo3-eda/
├── docs/                          # 文档目录
│   ├── 01-specification/          # 规格定义阶段
│   ├── 02-rtl-design/            # RTL设计阶段
│   ├── 03-verification/          # 功能验证阶段
│   ├── 04-synthesis/             # 综合阶段
│   ├── 05-place-route/           # 布局布线阶段
│   ├── 06-timing-analysis/       # 时序分析阶段
│   ├── 07-physical-verification/ # 物理验证阶段
│   └── 08-tapeout/               # 流片阶段
├── design/                        # 设计文件
│   ├── rtl/                      # RTL源代码
│   ├── tb/                       # 测试平台
│   ├── scripts/                  # 自动化脚本
│   └── constraints/              # 约束文件
├── reports/                       # 各阶段报告
└── tools/                         # 工具配置
```

## 学习路径建议

1. **理论学习**: 先阅读 `docs/` 下各阶段的文档
2. **工具实践**: 使用开源工具 (如 OpenROAD, Yosys) 进行实践
3. **项目实践**: 完成一个小型设计 (如计数器、UART)

---

`★ Insight ─────────────────────────────────────`
1. **层次化理解**: 数字芯片设计是层层递进的过程 - 从抽象的行为描述到具体的物理实现，每层都验证设计的正确性
2. **迭代优化**: 实际流程中各阶段经常需要迭代，比如时序违例需要回到RTL修改或调整约束
3. **设计权衡**: 面积、功耗、性能是三个相互制约的目标，需要在整个流程中持续平衡

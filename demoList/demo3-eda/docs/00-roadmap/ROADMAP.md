# 数字芯片设计学习路线图

## 📍 当前阶段评估

### Level 1: 入门 (初学者)
- [ ] 了解数字电路基础 (与/或/非门、触发器)
- [ ] 理解二进制、十六进制
- [ ] 了解基本时序概念 (时钟、建立/保持时间)

### Level 2: RTL设计 (初级工程师)
- [ ] 熟练掌握Verilog/SystemVerilog语法
- [ ] 能实现状态机、FIFO、计数器等基本模块
- [ ] 理解可综合性编码风格
- [ ] 能编写简单Testbench

### Level 3: 验证工程师 (中级)
- [ ] 掌握UVM验证方法学
- [ ] 能编写覆盖率驱动的验证环境
- [ ] 理解功能覆盖率、代码覆盖率
- [ ] 会使用断言 (SVA)

### Level 4: 综合与DFT (高级)
- [ ] 理解综合流程和SDC约束
- [ ] 能分析时序报告并进行优化
- [ ] 掌握DFT技术 (扫描链、JTAG、LBIST)
- [ ] 理解不同工艺角的影响

### Level 5: 后端设计 (专家)
- [ ] 掌握Floorplanning、Placement、Routing
- [ ] 理解CTS、时钟树综合
- [ ] 能进行DRC/LVS检查和修复
- [ ] 理解信号完整性、电源完整性

### Level 6: 全流程专家 (架构师)
- [ ] 完整走通从规格到流片的全流程
- [ ] 能进行架构级权衡 (PPA: 性能、功耗、面积)
- [ ] 理解先进工艺挑战 (7nm、5nm)
- [ ] 有实际流片经验

---

## 📚 分阶段学习路径

### 阶段1: 基础夯实 (2-3个月)

#### 目标
掌握数字逻辑基础和Verilog语法

#### 学习内容
1. **数字逻辑基础** (2周)
   - 逻辑门与布尔代数
   - 组合逻辑与时序逻辑
   - 状态机设计
   - 推荐教材: "数字电子技术基础"

2. **Verilog/SystemVerilog** (4周)
   - 基本语法与数据类型
   - 行为建模与结构建模
   - 任务与函数
   - 接口与程序包
   - 推荐教材: "SystemVerilog for Design"

3. **计算机组成原理** (4周)
   - 数据表示与运算
   - 指令系统
   - CPU基本结构
   - 推荐教材: "计算机组成与设计"

#### 实践项目
- [ ] 设计4位加法器
- [ ] 设计交通灯控制器 (状态机)
- [ ] 设计简单计数器

---

### 阶段2: RTL设计深入 (3-4个月)

#### 目标
能独立完成中等复杂度模块设计

#### 学习内容
1. **常用接口协议** (4周)
   - UART、SPI、I2C
   - APB、AHB、AXI
   - 推荐资源: ARM官方协议文档

2. **复杂模块设计** (6周)
   - FIFO设计 (同步/异步)
   - 存储控制器
   - 中断控制器
   - DMA控制器

3. **代码质量** (2周)
   - Lint检查工具使用
   - 代码规范 (设计中译本)
   - 可综合性编码

#### 实践项目
- [ ] 完整UART控制器 (本项目)
- [ ] SPI Master控制器
- [ ] 简易DMA控制器

---

### 阶段3: 功能验证 (3-4个月)

#### 目标
掌握UVM验证方法学

#### 学习内容
1. **验证基础** (4周)
   - 验证计划编写
   - Testbench结构
   - 激励生成与响应检查
   - 覆盖率概念

2. **SystemVerilog验证特性** (4周)
   - 接口与虚拟接口
   - 类与继承
   - 约束随机化
   - 断言 (SVA)

3. **UVM方法学** (4周)
   - UVM组件层次
   - Sequence机制
   - Scoreboard与Monitor
   - 寄存器模型 (RAL)

#### 实践项目
- [ ] 为UART编写UVM验证环境
- [ ] 实现随机化激励
- [ ] 达到100%功能覆盖率

---

### 阶段4: 综合与时序 (3-4个月)

#### 目标
理解综合流程, 能进行时序分析

#### 学习内容
1. **综合基础** (4周)
   - RTL到门级转换
   - 工艺库与标准单元
   - 面积/时序/功耗优化
   - SDC约束编写

2. **静态时序分析** (4周)
   - Setup/Hold时序检查
   - 时钟树与时钟偏斜
   - 多角分析与时序例外
   - 工具使用 (PrimeTime/OpenSTA)

3. **DFT (可测性设计)** (2周)
   - 扫描链插入
   - JTAG与边界扫描
   - 存储器BIST

#### 实践项目
- [ ] 使用Yosys综合UART设计
- [ ] 分析并修复Setup/Hold违例
- [ ] 插入扫描链

---

### 阶段5: 物理设计 (4-6个月)

#### 目标
掌握完整P&R流程

#### 学习内容
1. **布局规划** (4周)
   - Floorplan设计
   - 电源网络规划
   - 宏单元放置

2. **布局布线** (6周)
   - 标准单元放置
   - 时钟树综合 (CTS)
   - 布线策略

3. **物理验证** (4周)
   - DRC规则与修复
   - LVS检查
   - 天线效应修复

#### 实践项目
- [ ] 使用OpenROAD完成UART P&R
- [ ] 修复所有DRC/LVS错误
- [ ] 通过时序签收

---

### 阶段6: 流片准备 (2-3个月)

#### 目标
准备流片数据, 理解制造流程

#### 学习内容
1. **DFM (可制造性设计)** (4周)
   - 金属填充
   - 冗余通孔
   - 天线效应修复

2. **封装与测试** (4周)
   - 封装类型选择
   - ATE测试向量生成
   - 良率分析

3. **流片流程** (2周)
   - 数据包准备
   - 晶圆厂沟通
   - 进度跟踪

#### 实践项目
- [ ] 准备完整流片数据包
- [ ] 生成ATE测试向量
- [ ] 编写流片检查清单

## 💼 职业发展

### 职位晋升路径
```
初级工程师 (0-2年)
  → 设计/验证工程师
  → 掌握基本技能

中级工程师 (2-5年)
  → 高级工程师
  → 独立负责模块
  → 指导新人

高级工程师 (5-8年)
  → 技术专家/架构师
  → 架构设计
  → 技术决策

专家/管理 (8年+)
  → 首席架构师
  → 技术总监
  → CTO
```

### 薪资范围 (中国大陆)
- **初级**: 15-25万/年
- **中级**: 30-50万/年
- **高级**: 60-100万/年
- **专家**: 100万+/年

### 就业方向
- **芯片设计公司**: 海思、紫光、联发科...
- **FPGA公司**: Xilinx、Intel FPGA...
- **互联网公司**: 阿里平头哥、百度芯片...
- **创业公司**: AI芯片、汽车电子...

---

`★ Insight ─────────────────────────────────────`
1. **深度 > 广度**: 专精某个方向 (验证/后端) 比全而不精更有价值
2. **项目经验为王**: 真实流片经验比100个课程更有说服力
3. **持续学习**: 半导体技术更新快, 需要终身学习
`─────────────────────────────────────────────────`

选择适合你的路径, 开始学习之旅！ 🚀

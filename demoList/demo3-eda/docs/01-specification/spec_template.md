## 1. 功能概述

简要描述芯片/模块的主要功能。

### 示例
```
本设计是一个通用的UART (Universal Asynchronous Receiver/Transmitter)
控制器, 支持标准串行通信协议。主要特性包括:

- 可配置波特率 (9600, 115200)
- 8位数据位, 1位停止位, 无校验位
- 发送/接收各16字节FIFO
- APB总线接口
- 可编程中断
```

#### CTRL (0x00) - 控制寄存器

| Bit | 名称 | 复位值 | 访问 | 说明 |
|-----|------|--------|------|------|
| 0 | `TX_EN` | 0 | RW | 发送使能 |

| 2 | `LOOPBACK` | 0 | RW | 环回测试模式 |

| Bit | 名称 | 复位值 | 访问 | 说明 |

| 1 | `TX_FULL` | 0 | RO | 发送FIFO满 |

## 4. 功能描述

### 4.1 发送流程

```
1. CPU检查TX_EMPTY状态
2. 写入数据到TX_DATA寄存器
3. 数据进入发送FIFO
4. UART模块自动将数据转换为串行比特流
5. 通过TX引脚发送
6. 发送完成后置位TX_EMPTY并产生中断
```

### 4.2 接收流程

```
1. UART模块监控RX引脚
2. 检测起始位
3. 按配置的波特率采样数据位
4. 数据进入接收FIFO
5. 置位RX_EMPTY并产生中断
6. CPU读取RX_DATA寄存器
```

### 4.3 波特率生成

```
波特率分频值 = 时钟频率 / (16 × 目标波特率)

例如: 50MHz时钟, 115200波特率
DIV = 50,000,000 / (16 × 115200) = 27.1 ≈ 27
```

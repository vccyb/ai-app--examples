# EDA Agent 交互式使用文档

## 快速开始

### 启动系统

```bash
# 进入项目目录
cd eda-agent

# 启动交互式系统
python3 main_interactive.py
```

### 系统流程

```
======================================================================
               EDA Agent 系统启动
======================================================================

可用场景：
  1. verify - 验证模块是否达到设计目标
  2. report - 生成和导出设计报告

提示：输入场景编号或名称选择场景
      输入 'q' 退出系统
======================================================================

你：1
======================================================================
已选择场景: verify
───────────────────────────────────────────────────────────────────────
进入场景：verify
───────────────────────────────────────────────────────────────────────

请输入任务描述（或 'q' 返回到主菜单）：
提示：输入如 '验证模块A的时序<10ns'

[verify] >
```

## 可用命令

| 命令 | 说明 |
|------|------|
| `1` 或 `verify` | 选择验证场景 |
| `2` 或 `report` | 选择报告场景 |
| `scenes` 或 `场景` | 列出所有场景 |
| `help` 或 `帮助` | 显示帮助信息 |
| `q` 或 `退出` | 退出系统 |

## 场景内命令

| 命令 | 说明 |
|------|------|
| `q` | 退出当前场景，返回主菜单 |

## 架构说明

### 两层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    EDA Agent 架构                   │
├─────────────────────────────────────────────────────────────────┤
│                                                     │
│  ┌───────────────┐    ┌──────────────┐    │
│  │ Scene Layer    │    │Service Layer│    │
│  │ - verify      │    │- LLM       │    │
│  │ - report      │    │- RAG       │    │
│  │ - ...         │    │- EDA       │    │
│  └───────┬───────┘    │- State     │    │
│         │             │             │    │

│  ┌─────────────┐     │             │    │

│         │             │             │    │

│    用户输入 → 场景.run() → 服务调用 → 完成  │

```

### 用户交互流程

```
1. 用户选择场景
      ↓
2. 进入场景内部循环
      ↓
3. 用户输入任务描述
      ↓
4. 场景处理（调用 LLM 生成执行计划）
      ↓
5. 按计划调用服务（RAG/EDA/State）
      ↓
6. 返回结果
      ↓
7. 询问是否继续
```

## LLM 的作用

### 在新架构中

**LLM 只负责任务规划**：
- 用户输入："验证模块A的时序<10ns"
- LLM 生成执行步骤：
  ```json
  {
    "steps": [
      {"action": "查询规范", "service": "rag_service", "params": {"module": "模块A"}},
      {"action": "运行仿真", "service": "eda_service", "params": {"module": "模块A"}},
      {"action": "比较结果", "params": {"target": "<10ns", "actual": "{{timing}}"}}
    ]
  }
  ```
- 场景按步骤调用服务

### 在旧架构中

**LLM 负责太多**：
- 意图识别（预测用哪个场景）
- 任务解析（提取参数）
- 生成执行计划
- 调用服务

## 配置说明

### 环境变量

```bash

python3 main_interactive.py

# 或使用真实 Qwen API
export QWEN_API_KEY="your_api_key"

```

```bash

python3 main_interactive.py --llm claude  # 使用 Claude
python3 main_interactive.py --llm qwen    # 使用 Qwen
python3 main_interactive.py --llm mock    # 使用 Mock（默认）
```

## 场景说明

### verify（验证场景）

**功能**：验证模块是否达到设计目标

**可用服务**：
- `rag_service`：查询模块规范
- `eda_service`：运行仿真获取实际指标
- `state_service`：保存结果

**使用示例**：
```
[verify] > 验证模块A的时序是否<10ns
[verify] > 验证模块B的功耗是否<50mW
[verify] > 查询模块C的设计规范
```

### report（报告场景）

**功能**：生成和导出设计报告

**可用服务**：
- `rag_service`：查询历史数据
- `eda_service`：获取仿真结果
- `state_service`：读取历史数据

**使用示例**：
```
[report] > 生成模块A的验证报告
[report] > 导出所有模块的性能对比
```

## 开发说明

### 添加新场景

1. 在 `src/scenes/` 创建新文件，如 `optimize.py`

```python
# src/scenes/optimize.py
from scenes.base import BaseScene

class OptimizeScene(BaseScene):
    def __init__(self, services: Dict):
        super().__init__(
            name="optimize",
            description="优化场景 - 迭代优化直到达到目标",
            keywords=[],
            services=services
        )

    def match(self, user_input: str) -> float:
        return 0.0

    def run(self, user_input: str):
        # TODO: 实现优化逻辑
        yield self._create_done_message({})
```

2. 在 `main_interactive.py` 中注册

```python
from scenes.optimize import OptimizeScene

# 在 main() 函数中添加
manager.register_scene(OptimizeScene(services))
```

3. 重启系统，新场景自动可用

### 修改场景逻辑

场景的 `run()` 方法是生成器，可以 yield 不同类型的消息：

```python
def run(self, user_input: str):
    # 信息消息
    yield self._create_info_message("正在处理...")

    # 步骤结果
    yield self._create_step_result_message(
        step=1,
        result={"status": "SUCCESS"},
        status="SUCCESS"
    )

    # 询问
    yield self._create_ask_message(
        question="是否继续？",
        options=["是", "否"]
    )

    # 完成
    yield self._create_done_message({"summary": "完成"})
```

# 《没钱修什么仙》角色人物站 - 需求文档

## 📌 项目概述

**项目名称**: 没钱修什么仙 - 角色人物站
**项目类型**: 3D 交互式角色展示网站
**核心内容**: 基于《没钱修什么仙？》（作者：熊狼狗）小说的主角团角色展示

---

## 🎯 项目目标

创建一个具有视觉冲击力的 3D 角色展示网站，以沉浸式的方式呈现小说主要角色的信息、特点和关系。

---

## 👥 角色范围（第一阶段）

### 1. 张羽（主角）
- **身份**: 嵩阳高中学生，出身贫寒的修仙者
- **特点**:
  - 成绩优异但家庭贫困
  - 修仙天赋惊人，引起高层关注
  - 通过"法力贷"、"修仙贷"等借贷方式维持修炼
  - 陷入债务恶性循环
- **修仙境界**: 炼气境 → 筑基境
- **性格标签**: 坚韧、机智、贫穷、乐观

### 2. 白真真
- **身份**: 张羽的高中同学/好友，土生土长的昆墟人
- **特点**:
  - 经济困难，长期依赖张羽支持
  - 与邪神福姬签订契约获得外挂能力
  - 存在地球人思想与昆墟思想的内心冲突
  - 真正被同化的昆墟人
- **修仙境界**: 筑基境（第230章"超越声音"）
- **性格标签**: 忠诚、矛盾、依赖、成长

## 🎨 技术方案

### 技术栈
| 类别 | 技术选择 |
|------|----------|
| 前端框架 | Vue 3 (Composition API) |
| 构建工具 | Vite |
| 3D 引擎 | Three.js |
| 动画库 | GSAP (用于平滑过渡动画) |
| UI 组件 | 自定义 + Tailwind CSS |
| 部署方式 | 静态页面 |

### 选择理由
- **Vue 3**: 响应式数据绑定，便于管理角色状态
- **Three.js**: 成熟的 Web 3D 引擎，功能强大
- **GSAP**: 专业动画库，可实现流畅的 3D 过渡效果
- **静态部署**: 无需后端，便于托管和访问

## 🎬 核心功能设计

### 1. 3D 场景展示

#### 1.1 场景设计
- **背景**: 修仙主题的 3D 空间
  - 漂浮的灵石/法阵
  - 粒子效果（灵气粒子）
  - 渐变天空盒（从夜空到仙界云雾）

#### 1.2 角色展示方式
- **方案**: 2D 角色立牌 + 3D 场景背景
  - 角色立绘作为带透明通道的图片
  - 在 3D 空间中以"立牌"形式展示
  - 支持鼠标拖拽旋转查看（3D 卡片效果）
  - 角色切换时有平滑的 3D 过渡动画

#### 1.3 交互功能
- **鼠标交互**:
  - 拖拽旋转视角
  - 滚轮缩放
  - 点击角色卡片触发详情弹窗
- **角色切换**:
  - 底部/侧边角色选择器
  - 切换时 3D 相机运镜效果
  - 当前高亮的角色有光效环绕

### 2. 角色信息展示

#### 2.1 主展示区
- **角色立绘** (3D 立牌形式)
- **角色名称** (古风字体，带发光效果)
- **身份标签** (如"嵩阳高中学生"、"昆墟人")

#### 2.2 详情面板（点击展开）
- **基础信息**:
  - 姓名、身份、性格标签
- **修仙属性**:
  - 当前境界（带进度条可视化）
  - 法力值（0-100）
  - 肉体强度（0-10 炼气境 / 0-20 筑基境）
- **背景故事**:
  - 简短角色简介（200字以内）
- **代表台词**:
  - 1-2 句经典台词，带打字机效果
- **角色关系**:
  - 与其他角色的关系连线/描述

### 3. 视觉效果

#### 3.1 色彩主题
- **主色调**:
  - 深蓝/紫色（神秘修仙氛围）
  - 金色点缀（灵气/法力效果）
- **渐变背景**: 深空蓝 → 紫色云雾

#### 3.2 特效
- **粒子系统**: 漂浮的灵气粒子
- **光效**: 角色选中时发光光环
- **过渡动画**: 角色切换时的 3D 翻转/淡入淡出
- **文字效果**: 标题发光、台词打字机效果

## 📊 角色数据结构

```typescript
interface Character {
  id: string;
  name: string;
  title: string;           // 如"嵩阳高中学生"
  avatar: string;          // 角色立绘路径
  tags: string[];          // 性格标签

  // 修仙属性
  cultivation: {
    realm: string;         // 境界：炼气境/筑基境
    mana: number;          // 法力值 0-100
    bodyStrength: number;  // 肉体强度
    realmProgress: number; // 境界进度 0-100
  };

  // 描述信息
  description: string;     // 背景简介
  quotes: string[];        // 代表台词

  // 关系
  relationships: {
    characterId: string;
    relation: string;      // 如"好友"、"基友"
  }[];
}
```

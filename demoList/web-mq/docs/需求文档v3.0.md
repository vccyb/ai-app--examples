# 《没钱修什么仙》角色人物站 - 需求文档 v3.0

## 📌 项目概述

**项目名称**: 没钱修什么仙 - 赛博修仙角色人物站
**项目类型**: 3D 交互式角色展示网站 + 世界观介绍
**核心内容**: 基于《没钱修什么仙？》（作者：熊狼狗）小说的昆墟世界观与主角团展示
**视觉风格**: **赛博修仙 + 数据可视化**（深黑 + 霓虹色 + 数据流 + 全息界面）
**第一阶段内容**: 昆墟世界观页 + 张羽（男主角）+ 白真真（女主角）

---

## 🎯 项目目标

创建一个具有强烈"资本压榨+赛博修仙"视觉冲击力的3D展示网站，通过数据可视化和交互式设计，呈现昆墟世界的残酷与主角在债务修仙体系中的挣扎。

---

## 🌆 昆墟世界观（背景.json）

### 核心设定
- **空间结构**: 地上36层 + 地下18层，巨型修真-资本金字塔
- **权力结构**: 十大宗门 + 天庭八部正神垄断一切资源
- **核心标签**: 赛博修仙大金字塔、贷款修仙乐园、资本版轮回乐园、灵界互联网社会
- **世界性格**: 高度等级化、极端功利、表面现代文明实为血肉工厂

### 资本压榨系统
- **法力贷**: 借100年功力，30天后还150年+复利，违约则肉身崩解
- **教育贷**: 补课、药剂、灵根检测、功法版权全部需要贷款
- **医保系统**: 血条货币化，战斗治疗消耗医保额度
- **灵币体系**: 由正神发行的信息货币，锚定昆墟基础能源
- **灵界网络**: 精神互联网，控制考试、直播、转账、功法授权

### 上升通道
**唯一路径**: 考好高中 → 万法大学 → 十大宗门 → 成神入天庭
- 考进高中即仙凡分水岭
- 嵩阳高中要求入学前绝育、长期打针、极限训练
- 筑基资格证是前置门槛，无证书不得筑基

## 📊 数据可视化元素（新增核心功能）

### 1. 债务计数器（ Debt Counter ）
**位置**: 场景右上角，始终可见

**功能**:
- 实时滚动显示张羽的债务: **700,000+ 灵币**
- 数字霓虹粉红色，带滚动动画
- 下方小字显示: "法力贷 + 教育贷 + 修仙贷"
- 可选：点击展开详细债务明细

**技术实现**:
- 使用 GSAP 实现数字滚动动画
- 每3秒随机增加债务（模拟利息增长）

### 2. 层级结构图（ Layer Map ）
**位置**: 场景左侧，可折叠

**功能**:
- 垂直展示36层结构（地上36层 + 地下18层）
- 用高亮标注当前位置（第一层）
- 上层用金色，下层用灰色渐变
- 鼠标悬停显示层级名称和特点

**示例数据**:
```
▲ 第36层：天庭核心（金色）
...
▲ 第10层：万法大学（霓虹青）
...
▲ 第1层：嵩阳高中 / 贫民窟（当前 - 霓虹粉）
▼ 地下18层：魂修区 / 工厂区（深灰）
```

### 3. 法力贷计算器（ Spirit Loan Calculator ）
**位置**: 角色详情面板的"修仙功法"Tab中

**功能**:
- 输入借贷款项
- 显示日息、复利计算
- 可视化展示30天后需要偿还的功力
- **警示**: 当债务超过100万时，红色警报闪烁

**示例**:
```
借100年功力
├─ 免息期：30天
├─ 日息：0.5年功力/天
├─ 30天后需还：150年功力
└─ 违约后果：肉身崩解 ⚠️
```

### 4. 功力/法力进度条
**位置**: 角色详情面板

**功能**:
- 显示当前修仙境界（炼气境/筑基境）
- 用进度条可视化法力值（0-100）
- 显示肉体强度（0-10 炼气境）
- 霓虹青色进度条 + 发光效果

## 📊 数据结构设计

```typescript
interface Character {
  id: string;
  name: string;
  role: string;
  identity: string;
  tags: string[];
  personality: string[];

  // 功法能力
  abilities: {
    path: string;
    list: string[];
  };

  // 关键事件
  keyEvents: {
    title: string;
    description: string;
  }[];

  // 人际关系
  relationships: {
    target: string;
    label: string;
    description: string;
  }[];

  // 债务情况（新增）
  debt: {
    total: number;              // 总债务
    breakdown: {                // 债务明细
      type: string;             // 法力贷/教育贷/修仙贷
      amount: number;
    }[];
  };

  // 修仙数据（新增）
  cultivation: {
    realm: string;              // 炼气境/筑基境
    mana: number;               // 法力值 0-100
    bodyStrength: number;       // 肉体强度
    realmProgress: number;      // 境界进度
  };

  background: string;
  avatar: string;
}

// 世界观数据结构（新增）
interface WorldData {
  id: string;
  name: string;
  structure: {
    aboveGround: number;        // 地上36层
    belowGround: number;        // 地下18层
  };
  systems: {
    currency: string;           // 灵币
    network: string;            // 灵界网络
    debt: string[];             // 法力贷、教育贷等
  };
  layers: {
    level: number;
    name: string;
    description: string;
  }[];
}
```

## 🎨 视觉设计规范（赛博修仙版）

### CSS变量定义
```css
:root {
  /* 主色调 */
  --color-bg-dark: #0a0a0a;
  --color-bg-purple: #1a0a2e;

  /* 霓虹强调色 */
  --color-neon-pink: #ff006e;    /* 债务/危机 */
  --color-neon-cyan: #00f5ff;    /* 灵力/科技 */
  --color-neon-gold: #ffd700;    /* 灵币/财富 */

  /* 文字色 */
  --color-text-primary: #ffffff;
  --color-text-secondary: #e0e0e0;

  /* 玻璃态效果 */
  --glass-bg: rgba(255, 255, 255, 0.05);
  --glass-border: rgba(255, 255, 255, 0.1);

  /* 霓虹发光 */
  --glow-pink: 0 0 10px #ff006e, 0 0 20px #ff006e;
  --glow-cyan: 0 0 10px #00f5ff, 0 0 20px #00f5ff;
  --glow-gold: 0 0 10px #ffd700, 0 0 20px #ffd700;
}
```

### 动画效果
- **数据流**: 垂直下落的二进制代码 + 霓虹光点
- **扫描线**: 水平扫描线从上到下循环
- **霓虹闪烁**: 关键数据（债务）的呼吸灯效果
- **数字滚动**: 债务计数器的数字递增动画
- **全息投影**: 面板展开的从底部升起的3D翻转效果
